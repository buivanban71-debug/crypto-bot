# Crypto Bot

Bot theo dõi BTC và altcoin, chạy miễn phí trên GitHub Actions và gửi cảnh báo qua Telegram.

- Cảnh báo 15 phút/lần: RSI, biến động 24h, khối lượng, EMA20 cắt EMA50, kèm AI nhận định từ tin tức
- Bản tin thị trường 8h sáng mỗi ngày
- Backtest 3 chiến lược mỗi Chủ nhật
- Giao dịch giấy: 200 USDT ảo mỗi coin

Chỉ đọc dữ liệu, không đặt lệnh thật. Không phải lời khuyên đầu tư.
