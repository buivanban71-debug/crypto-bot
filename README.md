# Crypto Bot

Bot theo dõi BTC và altcoin, chạy miễn phí trên GitHub Actions và gửi cảnh báo qua Telegram.

- Cảnh báo 15 phút/lần: RSI, biến động 24h, khối lượng, EMA20 cắt EMA50 (khung 4h), kèm AI nhận định từ tin tức
- Bản tin thị trường 8h sáng mỗi ngày
- Theo dõi BTC, ETH, SOL
- Backtest 3 chiến lược trên 180 ngày (khung 1h và 4h) mỗi Chủ nhật
- Giao dịch giấy: 3 chiến lược song song, mỗi chiến lược 1.000 USDT ảo

Chỉ đọc dữ liệu, không đặt lệnh thật. Không phải lời khuyên đầu tư.
